# Правила выбора моделей

Эти правила действуют для всего проекта.

| Роль | Модель | Уровень рассуждений |
| --- | --- | --- |
| Главный оркестратор | GPT-6 Astra (`gpt-6-astra`) | High (`high`) |
| Субагенты по умолчанию | GPT-6 Sol (`gpt-6-sol`) | High (`high`) |
| Субагенты для простых задач, если такие задачи есть | GPT-6 Luna (`gpt-6-luna`) | High (`high`) |

Главный оркестратор разбивает работу на задачи, выбирает исполнителей, согласует результаты и проверяет итог.

Используй Luna для небольших, однозначных задач с понятным способом проверки: поиска файлов, точечных правок текста или механических изменений по заданному образцу. Для задач, требующих анализа, проектирования, отладки или работы с несколькими связанными компонентами, используй Sol. Если сложность неясна, выбирай Sol.

При запуске субагента явно задавай модель и уровень рассуждений `high`.
